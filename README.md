# Starry Night Landing Page

A simple landing page built as a practice project for learning HTML, CSS, and Flexbox. The design and color palette are inspired by a "Starry Night" theme.

## About The Project

This project is part of my journey to learn web development. The goal was to recreate a standard landing page layout (similar to The Odin Project curriculum) while applying a custom color scheme based on a provided image. The layout heavily relies on CSS Flexbox for positioning and alignment.

### Sections Included:

- **Header:** Logo and navigation links.
- **Hero Section:** Main title, subtext, call-to-action button, and a placeholder image.
- **Information Section:** A row of four cards with subtext.
- **Quote Section:** A testimonial block with italic text.
- **Call to Action:** A prominent box encouraging users to sign up.
- **Footer:** Copyright information.

## Built With

- **HTML5:** For structuring the content.
- **CSS3:** For styling and layout.
- **Flexbox:** Used extensively for layout management (rows, columns, centering, and spacing).
- **RGB Colors:** Used basic RGB values to match the moody, "Starry Night" aesthetic.

## What I Learned

Through this project, I practiced:

- Setting up a basic HTML document structure.
- Using CSS Reset (margin, padding, box-sizing) for consistent styling across browsers.
- Creating a centered container for content width control.
- **Flexbox Fundamentals:**
  - `display: flex`
  - `justify-content` (space-between, center)
  - `align-items` (center)
  - `flex-direction` (column)
  - `gap` for spacing elements easily.
- Using Git and GitHub for version control, making incremental commits for each section.

## How to Run This Project

1. Clone this repository or download the files.
2. Ensure you have an image file named `starry.jpg` in the same folder (or update the image path in `index.html`).
3. Open `index.html` in your web browser.
